# Ecliptica Boss Damage Log Reader
A fan made log reader for Ecliptica in VRChat. It does show timestamp, name of the boss, strike damage, non-strike damage (dots), duration, start phase % and DPS.

Known issues:
- Player Dead doesn't always show as its based on the log and for some reason it doesn't always appear.

P.S. Be nice to each other, please don't use it as DPS check for the group.
